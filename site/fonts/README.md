# Fonts

## Routed Gothic Wide

`routed-gothic-wide.woff2` is [Routed Gothic](https://github.com/dse/routed-gothic)
by Darren Embry, used for headings, navigation, and control labels.

Routed Gothic is a revival of the single-stroke lettering used on drafting
machines and engraved instrument panels — the same lineage as the Gorton
typefaces named in MIL-M-18012B for control-panel engraving. It suits a library
whose subject is addressing structure in a document by name rather than by
position.

The file here is the upstream `dist/ttf/routed-gothic-wide.ttf` converted to
WOFF2 for the web. Nothing else was changed: the glyph set is complete (488
glyphs), the family name is unmodified, and no subsetting was applied.
